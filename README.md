# こえ検索（ブラウザ版）

講座中の声を文字に起こし、話に出てきた言葉の写真（Wikipedia）を、2画面目（プロジェクター）に映すツールです。
ルビ付きの字幕も、その上に重ねて表示します。
失語症の方が、言葉だけでは何の話か分かりにくいときの手がかりにします。

**https://murakamimikiart-design.github.io/koe-kensaku/** を Google Chrome で開くだけで使えます。
インストールも、サーバーも、API キーもいりません。

## スマートフォンで使う

スマートフォンで開くと、写真と字幕をその画面の中に出す形になります（投影ウィンドウは開きません）。
大きな「聞き取り」ボタンを押すと始まります。Android の Chrome がいちばん安定します。iPhone（Safari）でも動きますが、聞き取りがときどき途切れることがあります。

## 始め方（パソコン）

1. 上の URL を Chrome で開く（はじめに「マイク」の許可を聞かれたら「許可」）
2. **O** キー → 投影ウィンドウが開きます（「ポップアップ」「ウィンドウ管理」の許可を聞かれたら「許可」）
3. 投影ウィンドウをプロジェクターの画面に置き、中をクリック（または **F** キー）で全画面
4. 操作画面の「**聞き取り**」ボタン（または **スペース** キー）で聞き取りを始めます。止めるまでずっと続きます

## できること

- **単語リスト**：設定の「単語リスト」に、映したい言葉を1行に1つ書きます
  - 言い方がいくつかあるときは「|」で区切ります：`ハチ公|はちこう`
  - 「=」の後ろに検索する言葉を書けます：`作業療法 = 作業療法 手芸`
  - 「=」の後ろに https:// から始まるアドレスを書くと、そのウェブサイトを映します（サイトによっては表示を断られます）
- **人物名の候補**：辞書で人物名らしい言葉を見つけ、履歴に候補として並べます（クリックで投影）
- **会話モード（簡易版・AI なし、はじめからオン）**：話に出てきた名詞（粘土、犬、脳、地名、作品名、失語症、作業療法 など）を辞書で見つけて投影します。「こと」「気持ち」「時間」のような写真にならない言葉は拾いません。設定で「少なめ」（固有名詞と漢字3文字以上の言葉だけ）にもできます
- **ルビ付きの字幕**：すべての漢字にルビを付けて、2行で表示します。1行は10秒まで。位置（上・下）は設定で選べます
- **文字起こしの記録**：聞き取りを止める（スペースキー）と、記録をテキストファイルでダウンロードします（Chrome のダウンロード先、ふつうは「ダウンロード」フォルダ）

1枚の写真は最低6秒見せます。続けて見つかった言葉は順番待ちになり、同じ言葉は2分間は出し直しません。

## キー（操作画面で）

| キー | 動作 |
|---|---|
| Space | 聞き取り 開始／停止 |
| O | 投影ウィンドウを開く |
| H | 写真を固定（話が進んでも切り替えない） |
| N | 人物名の候補を並べる ON／OFF |
| W | 単語リストの自動検索 ON／OFF |
| K | 会話モード（簡易版） ON／OFF |
| 1〜9 | 履歴の言葉をもう一度表示 |
| / | 手入力で検索 |
| + / − | 字幕の文字を大きく／小さく |
| C | 字幕を消す |
| F | 操作画面を全画面（投影ウィンドウでは、投影ウィンドウを全画面） |

## 知っておいてほしいこと

- 文字起こしには Chrome の音声認識を使います。インターネットにつながっている必要があります
- 写真は Wikipedia（日本語版）と Wikimedia Commons の記事の写真です。言葉そのものの記事を先に出しますが、関係の薄い写真が混ざることがあります
- 病気・けが・事故・戦争・災害などの記事（脳梗塞、脳出血 など）の写真は出しません。事故・戦争などの言葉は、会話モードでも拾いません
- 設定や単語リストは、使っているブラウザの中にだけ保存されます

## 使っているもの

- [kuromoji.js](https://github.com/takuyaa/kuromoji.js)（`lib/`、Apache License 2.0）と、その辞書（IPADIC）：人物名・会話モード・ルビ
- Chrome の Web Speech API：文字起こし
- Wikipedia / Wikimedia Commons の API：写真
